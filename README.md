Aplicación web interactiva (client-side) diseñada para apoyar a emprendedores en la gestión comercial y estrategia de precios. Esta herramienta permite calcular el precio de venta ideal basándose en costos de compra, fletes y gastos generales, desglosando impuestos (IVA) y márgenes de utilidad.

Características principales:

Perfiles de Negocio: Configuraciones predefinidas para distintos rubros (Minimarket, Ferretería, Boutique, Restaurante).

Escenarios de Temporada: Proyección de precios y márgenes para etapas de Avance, Temporada Normal, Liquidación y Remate.

Modos de Costeo: Distribución de costos indirectos de forma global (por orden) o individual (por producto).

Reportabilidad: Generación automática de informes en PDF usando jsPDF.

Persistencia: Guardado automático de datos en el navegador (LocalStorage) y exportación/importación de proyectos en JSON.

Tecnologías: HTML5, Bootstrap 5 y Vanilla JS (Sin backend).
